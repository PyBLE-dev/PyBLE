## Changes since the retained app build 5

The new candidate adds the complete offline Privacy policy from About and a
distinct build identity. The policy identifies the maintainer, effective date,
contact, optional GitHub traffic, direct BLE transfers and transport security,
permissions, retention/deletion, platform handling and website infrastructure.
Reading it preserves the running board session and editor/Blocks/console state.
The current app source also retains the named-pin Blocks support and iOS 15
deployment floor already present before this preparation.

No Android runtime dependency, BLE protocol, firmware image, analytics feature,
account, or network workflow was added for this handoff.
